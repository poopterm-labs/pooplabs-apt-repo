Poop Labs APT Repository

Debian and jailbreak packages maintained by poopterm-labs.

Add to Debian

Add this line to an APT source file, then run sudo apt update:

deb [trusted=yes] https://poopterm-labs.github.io/pooplabs-apt-repo/ ./

This unsigned repository includes the latest stable amd64 Poopterm package.

Add to Cydia

Add this source in Cydia:

https://poopterm-labs.github.io/pooplabs-apt-repo/
